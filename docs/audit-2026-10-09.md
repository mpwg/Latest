# Beta audit: 0.12-beta2

Baseline: `4c1e11181a32ef97827213bebd00e185e983a359`, tag `0.12-beta2`.
Audit date: 2026-10-09. Changes belong exclusively to `mpwg/Latest`.
`mangerlahn/Latest` is a read-only reference.

## Method and evidence limits

The review covered 64 Swift source files, private framework declarations,
configuration, resources and tests. All 146 open upstream issues were catalogued;
central discussions were inspected in detail. Isolated Swift probes used the
unchanged version and cask code. A harmless shell probe replaced the installer
with `/usr/bin/true` and executed only `printf` as an ordinary user. No root
exploit or user-app update was performed. Xcode was unavailable; static and
isolated evidence does not prove native installation.

## Findings and regression criteria

| ID | Priority | Cause and observed failure | Required change and regression |
|---|---|---|---|
| A01 | P1 | Root helper interpolates paths into bash; quotes break syntax, crafted paths execute additional commands. | Remove shell; fixed executable and argument array; quotes/metacharacters tests. |
| A02 | P1 | XPC accepts arbitrary package, target and receipt paths and deletes package parent. | Verified App Store IDs only; reject foreign clients, symlinks, changed tools and unrelated jobs. |
| A03 | P1 | Sparkle 2.5.1 lacks subsequent security fixes. | Pin 2.10.0; native signature/update test. Exploitability in Latest was not demonstrated. |
| A04 | P1 | Equal versions hash differently; A < B and B < A possible; 1.2 equals 1.2.0.1. | Structural equality, symmetric policies, unknown result; regression tests. |
| A05 | P1 | Remote exclusion list uses forced try/cast. | Validate status, size and shape; last known good cache. |
| A06 | P1 | installURL ignored; Bundle(identifier:) loses selected instance. | Canonical URL and fresh snapshot; duplicates use App Store. |
| A07 | P1 | XPC continuation may complete twice or never. | Single completion on reply, timeout, failure and cancellation. |
| A08 | P2 | App Store cancellation only finishes operation. | Owned job/process cancellation, honest install state and rescan. |
| A09 | P2 | Sparkle sleep/progress races; start failure continues. | Main-actor adapter with explicit lifecycle. |
| A10 | P2 | One empty minimum OS rejects entire cask catalogue. | Decode entries independently; valid/invalid neighbour regression. |
| A11 | P2 | Catalogue names stand in for Homebrew provenance. | Local cask ownership required; hints remain informational. |
| A12 | P2 | Missing HTTP status checks; global ATS exception. | HTTPS, bounded streaming, status validation, atomic cache. |
| A13 | P2 | Observers/directories/results lack consistent isolation. | Actor inventory, generations and cleanup. |
| A14 | P2 | Custom table diffing/drawing/animation. | SwiftUI lists, stable identities, accessible controls. |
| A15 | P2 | Original author's team, IDs, keys and feed. | Own release configuration and mutual signature checks. |
| A16 | P2 | Travis Xcode 12.2; mostly version tests. | Xcode 27 CI; core, integration, UI and privilege tests. |

The beta authenticates clients but does not validate paths. Eleven German
helper/toolbar translations were missing. Empty translation files are missing
translations, not proven build failures. All finding statuses must be verified
against the final implementation.
